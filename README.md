## 🚀 Getting Started

### Backend (Laravel)
1. Navigate to `backend` directory
2. Run `composer install`
3. Run `php artisan migrate --seed`
4. Run `php artisan serve`

### Frontend (React + Vite)
1. Navigate to `frontend` directory
2. Run `npm install`
3. Run `npm run dev`
